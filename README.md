# Roadtrip Animation

Roadtrip Animation built using HTML, CSS and JavaScript.

A lightweight, purely front-end animation that simulates a scenic road trip. It was created as a small web animation project to demonstrate CSS and JS-driven motion and layering.

## Features

- Pure HTML/CSS/JavaScript (no frameworks or build step required)
- Smooth animations and parallax-like layering
- Lightweight and easy to customize

## Files

- `index.html` — markup and structure
- `style.css` — main styles and animations
- `Screenshot 2024-08-30 132814.png` — preview image used in this README

## How to run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Roadtrip-Animation.git

2. Open `index.html` in your browser (double-click the file or serve it with a static server).

That's it — the animation runs entirely in the browser.

## Customize

- Edit `style.css` to change colors, speeds, and layout.
- Add or replace background/foreground images to change the scene.
- Use `index.html` to add or rearrange elements shown in the animation.
